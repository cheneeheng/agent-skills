# ceh-dev-tools

Developer productivity agents for repository exploration and codebase orientation.

## Agents

### `repo-tree-mapper`

Generates an annotated, clickable `REPO_MAP.md` from any repository. Every file and folder is linked and labeled with its purpose.

**Invoke:** `@"ceh-dev-tools:repo-tree-mapper (agent)"`

**Auto-triggers on:** "map this codebase", "show me the repo tree", "what's in this repo", "project structure overview", "document the project structure", or any onboarding/orientation request.

**Output:** `REPO_MAP.md` (or a user-specified path) containing:
- Nested link tree with `📁`/`📄` icons and relative links
- Per-entry descriptions explaining purpose, not just names
- **Highlights** section: entry points, architecture patterns, notable gaps

**Output example:**

```markdown
# Repo Map — acme-api

_Generated by `repo-tree-mapper`. 142 files, primarily TypeScript. Next.js web application._

## Structure

- 📁 **[src/](./src/)** — Application source
  - 📁 **[src/api/](./src/api/)** — Route handlers
    - 📄 [`auth.ts`](./src/api/auth.ts) — JWT login and token refresh
  - 📄 [`index.ts`](./src/index.ts) — Entry point: loads config, starts server
- 📄 [`package.json`](./package.json) — Dependencies; scripts: dev, build, test

## Highlights

- **Entry point:** `src/index.ts`
- **Architecture:** Express API, layered (routes → services → db)
- **Missing:** No CI config found
```

## Scripts

### `scripts/walk-repo.sh`

Bash helper used internally by `repo-tree-mapper` to enumerate repository contents.

```bash
bash scripts/walk-repo.sh [target_dir] [max_depth]
```

| Arg | Default | Notes |
|-----|---------|-------|
| `target_dir` | `.` | Directory to walk |
| `max_depth` | `8` | Recursion limit; use 4-5 for large repos |

- Uses `git ls-files` inside a git repo (respects `.gitignore`)
- Falls back to `find` outside git repos
- Always prunes: `node_modules/`, `.git/`, `venv/`, `__pycache__/`, `dist/`, `build/`, `.next/`, etc.

## Installation

```
/plugin install ceh-dev-tools@ceh-plugins --scope user
```

Or manually in `~/.claude/settings.json`:

```json
{ "plugins": [{ "path": "~/agent-skills/ceh-dev-tools" }] }
```

# Architecture Decision Records

Format and lifecycle for recording durable architectural decisions. An ADR is required whenever
a choice is significant enough that a future developer would be confused without the context,
or reversing it would require a migration or broad refactor.

Read [../architecture-design/references/adrs.md](../architecture-design/references/adrs.md)
and apply the format and lifecycle rules defined there.

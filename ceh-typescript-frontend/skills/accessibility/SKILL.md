# Accessibility

Keyboard accessibility requirements, alt attributes on images, semantic HTML element usage,
and svelte-check a11y enforcement. All a11y warnings from svelte-check must be fixed before
opening a PR.

Read [../typescript-frontend/references/accessibility.md](../typescript-frontend/references/accessibility.md)
and apply the rules defined there.

# Coding Style

`type` vs `interface` conventions, `const` assertions instead of TypeScript enums, naming
conventions for components/stores/constants, three-group import ordering with the `$lib` alias,
and JSDoc requirements on all exported symbols.

Read [../typescript-frontend/references/coding-style.md](../typescript-frontend/references/coding-style.md)
and apply the conventions defined there.
